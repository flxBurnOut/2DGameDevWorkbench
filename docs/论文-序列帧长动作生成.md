## 1. 问题背景、核心洞察与主线

### 1.1 为什么 2D 游戏精灵不是普通短视频

开放域视频生成可以容忍轻微抖动、边缘漂移或道具微变；2D 游戏精灵则是受**硬性游戏不变量（Hard Game-Readiness Invariants）**约束的状态机资产：

- **角色动作**必须守住地面基线、锚点、碰撞体积与随身装备一致性；
- **交互物多状态链（A → B → C）**必须保持底座与非活动外壳静止、刚体部件尺度不变。

商用与闭源动画生成器大多属于**短视界端点条件黑盒生成器（Black-Box Short-Horizon Endpoint-Conditioned Generators）**：单次只能生成固定短视界内的帧序列，权重与隐状态不可访问、不可微调，也不提供原生空间蒙版或骨骼硬锁定。制作长动作或多状态链只能分段接续。

### 1.2 核心洞察

黑盒分段接续存在两个紧耦合的难点：

1. **隐性漂移与 VLM 裁判的双向失灵**：分段接续最致命的不是明显崩坏，而是“单看合理、实则破坏游戏不变量”的隐性漂移跨段累积。若直接用视觉语言模型（VLM）自动验收，会同时出现两类系统性错误：
   - **错误拒绝（False Rejects）**：把正常的身体遮挡、透视缩短或挥砍残影误判为装备丢失/断裂，或把规划阶段脑补出的细节当成用户硬性要求；
   - **错误放行（False Accepts）**：多视角复核时轻易推翻独立检查发现的局部缺陷，或漏判像素级的地面基线偏移、面积跳变、固定底座位移与刚体杆长伸缩。
2. **只拦不修无法交付，全段重抽既贵又不稳**：纯拒稿只能拦住坏帧进入下一段，但每次发现局部瑕疵都整段重画成本高昂，还会破坏原本满意的动作躯干或相邻接缝。由于黑盒模型缺乏原生空间蒙版，本地后合成虽能锁住选区外像素零改动，却不能自动保证边界与动作连续（“域外零渗漏 $\neq$ 接缝连续”），因此需要分层局部修复配前后解耦复核。

### 1.3 全文故事线

- **痛点**：黑盒短视界生成器分段接续时，隐性游戏不变量跨段漂移；纯 VLM 自动检查受困于“遮挡错误拒绝”与“几何错误放行”，全段重画昂贵且不稳定。
- **思路**：把分段检查点建模为**选择性预测（Risk–Coverage Control）**问题——用程序化弃权守卫和确定性像素/几何探针双向约束 VLM，再通过保不变性的分级修复处理被拦下的局部缺陷，仅在必要时升级人工裁决或整段重画。
- **方法**：提出 **Verify Before You Chain (VBYC)** 框架，包含可编译状态转移合同、守卫检查点（Guarded Checkpoints）与 L1–L4 有界分级修复（Bounded Tiered Repair）。
- **验证**：用按版本分层的历史真实作业做客观漂移与失败分析；在双人独立标注的冻结语料上对比 2 次基线与等调用次数（5 次）无守卫 VLM 投票基线；在受控冻结协议下评估五组工作流与 `redraw_only` 消融的盲评可用率、API 成本与人工升级率权衡。

## 2. 核心学术贡献

1. **黑盒链式精灵生成形式化与跨段漂移实证**：将角色长动作与交互物多状态链统一建模为短视界黑盒生成器下的带不变量状态转移问题 $(\Delta, \mathcal{I})$；基于按版本分层的历史真实作业，结合人工失败分类与客观几何/色彩指标，量化隐性漂移随段数累积的规律及角色/交互物的失效差异。
2. **融合程序化弃权守卫与统一确定性探针的守卫检查点（Guarded Checkpoints）**：在防目标漂移合同与上下文隔离多视角审计之上，构建双向可见性自洽校验、矛盾不沉默覆盖（No-Silent-Override）以及覆盖角色与交互物的确定性像素/几何探针；在冻结语料上相对等调用次数（5 次）无守卫 VLM 基线验证其风险–覆盖率（Risk–Coverage）净收益。
3. **L1–L4 有界分级修复与端到端权衡实证**：建立从零生成费像素/固定区原语（L1）、后合成受限外观编辑（L2，配目标达成与区域保持解耦复核）到局部窗口重绘（L3）和整段重画（L4）的四级修复协议，并在统一冻结协议下量化五组接续策略与 `redraw_only` 消融在盲评可用率、API 费用与检查点人工升级率上的权衡。

## 3. 问题形式化与统一表示

### 3.1 黑盒短视界生成器抽象

将底层动画生成器抽象为受限黑盒函数：
$$G(I_{\text{start}}, p, I_{\text{end}}^{\text{opt}}, L, s) \to (F_1, \dots, F_L)$$
其中 $I_{\text{start}}$ 为真实首帧图像，$p$ 为受字数上限约束的文本条件，$I_{\text{end}}^{\text{opt}}$ 为可选末端引导图，$L \le L_{\max}$ 为单次最大帧数，$s$ 为随机种子。生成器权重不可访问、不可微调，且无原生空间蒙版或骨骼锁定。给定目标状态变化 $\Delta$ 与硬性不变量 $\mathcal{I}$，需经 $K$ 个分段产出满足引擎锚点、碰撞与状态机契约的可用序列帧。

### 3.2 角色长动作与交互物状态链的统一框架

两类资产共用同一套“状态转移合同 $(\Delta, \mathcal{I})$ + 哈希冻结真实帧检查点 + 守卫与分级修复”机制，仅动态目标、不变量与确定性探针维度不同：

| 维度 | 角色长动作（主实验：柔性运动） | 交互物多状态链（刚体压力测试 + 确定性修复延伸） |
| --- | --- | --- |
| 首帧输入 | 标准画布角色原图 | 标准画布物品原图（原生像素图或经确定性降采样输入，按来源记录） |
| 分段语义 | 连续长动作的动作阶段（如蓄力 → 挥砍 → 收势） | 具名状态间的有向过渡（A → B → C），可用状态骨架锁定段数 |
| 接续规则 | 确认后的真实播放末帧作为下段唯一合法起点 | 确认末帧同时登记为目标状态图；可先单锁状态图，续段仍需整段过渡通过 |
| 动态目标 $\Delta$ | 关键姿势变化、重心转移、运动路径与节奏边界 | 目标终态外观、运动部件位移/旋转轨迹及末态停留 |
| 硬不变量 $\mathcal{I}$ | 角色身份、随身装备持久性、地面基线、朝向与接缝连贯 | 固定底座/外壳位置、外轮廓、刚体尺度、触发与碰撞对齐 |
| 确定性探针 | 地面基线偏移、相对原图面积变化、质心速度跳变、调色板偏离 | 扣除运动遮挡后的固定区像素变化；平面内旋转检验枢轴–端点铰接半径守恒（平面外透视跳过半径校验） |
| 有界修复 | L1 精准像素/色表替色、L2 区域锁定外观编辑、L3 窗口重绘、L4 整段重画 | 在通用 L1–L4 之上，L1 另含固定区遮挡感知回填（T1）与不裁切边缘前景的整数对齐（T3） |

## 4. VBYC 方法：合同、守卫检查点与分级修复

### 4.1 防目标漂移的可编译状态转移合同

为抑制自然语言规划常见的“装备脑补”与“提示超限截断/提前抢演”，规划分为两步：

1. **首轮上下文隔离与原文逐字溯源**：外观观察与运动规划在首轮隔离。角色任务首次外观观察屏蔽用户动作文本，只看原图记录外观与持械状态，避免动作词诱发幻觉。汇总需求合同时，程序将用户原话与状态骨架拼成真值语料，逐条核对模型标为“用户要求”的条款是否属于原文精确子串——未命中者一律降级为“专家推测”，并把逐字原文写回合同。附带视觉结构时，部件引用受可见部件白名单约束，且交互物强制将可见部件互斥完备地划分为运动部件与固定部件。
2. **确定性分段简报编译**：不让模型自由编写单段底层绘图提示词。协调者只填写结构化阶段目标、全局关键帧路标、运动约束和三态段尾边界（过境连续 / 自然收势 / 有意停留，过境段禁止在段尾停留），再由编译器确定性地把全局帧号映射为段内局部坐标，组装标准化 12 槽绘图简报并校验长度上限；超限时退回精确修改，不静默截断。

### 4.2 守卫检查点（Guarded Checkpoints）

每个分段的验收被建模为三态选择性预测：**一致通过**、**明确拦截**或**显式弃权并升级人工裁决（Abstain / Escalate）**。

1. **先观察后审计与多视角争议核实**：
   - 两步基线先在屏蔽合同的前提下按 `[1..N]` 逐帧记录姿态、装备与相邻帧变化，再对照合同分维度审计（角色：完整性、装备、节奏；交互物：状态帧、过渡、固定部件）。
   - 多视角审计使用**同一 VLM 配置**在隔离上下文中分别从“外观身份”和“运动时序”视角复核（*Context-Isolated Multi-Perspective Auditing*，非多模型集成）。只要基线与两位独立视角不全为高置信通过——包括分歧、不确定，以及三方一致判失败时的缺陷核实——就触发至多一次争议复核。复核附带共享源坐标裁切并整数倍最近邻放大的聚焦图板，输出“满足、实质缺陷、审美偏好、证据不足”四分类。
2. **三类程序化弃权守卫**：
   - **最小帧证据与非对称置信门限**：所有引用帧号必须落在有效帧范围内，完整性与时序维度须引用足够多的不同帧，不足即降级弃权；通过与失败采用非对称置信门限，工作点与灵敏度在离线语料上经阈值扫描评估。
   - **双向可见性自洽守卫**：要求模型在装备与固定部件维度同步报告可见状态、遮挡/透视说明及前后参考帧（仅检验自报语义与帧索引的自洽性，不声称三维几何重建）。本地规则双向拦截：判“失败”但缺少可见部位矛盾帧或合理遮挡排除时降级弃权（压低错误拒绝）；判“通过”但存在未解释不可见区间或拿观察帧自证上下文时也降级弃权（压低错误放行）。
   - **多级不沉默覆盖（No-Silent-Override）**：争议复核单方面翻案基线非通过项、交出空可见性证据试图抹去专家疑点，或单方面推翻高置信可见矛盾结论时，一律保留原始分歧并强制转人工升级，不用投票掩盖冲突。
3. **角色与交互物统一的确定性探针（Fail-Closed）**：
   - 同步运行零生成费的确定性测量探针弥补 VLM 几何盲区：角色侧度量地面基线偏移、前景面积变化、质心速度跳变与调色板偏离；交互物侧经本地掩码追踪扣除运动部件合法遮挡后，度量固定区像素变化，并在合同标明画布平面内旋转时校验枢轴–端点铰接半径守恒（平面外透视跳过半径校验）。
   - 若 VLM 判通过但确定性探针越界，或必需追踪信号不可用，检查点按 Fail-Closed 原则降级为弃权升级。最终确认的真实播放帧连同版本哈希固化为下一段唯一起点；若目标姿势提前到达，支持人工显式截尾锁定较早锚点帧。

### 4.3 L1–L4 有界保不变性分级修复

检查点拦下局部缺陷后，按修改半径与生成模型参与度递增提供四级修复：

| 级别 | 机制 | 调用绘图模型 | 作用域与不变性保障 |
| --- | --- | --- | --- |
| L1 确定性原语 | 精准像素/色表替色、擦除补洞；交互物固定区遮挡感知回填（T1）与不裁切边缘前景的整数对齐（T3） | 否 | 零生成费；跳过已锁定边界帧；核验授权选区外 RGBA 四通道零改动 |
| L2 区域锁定外观编辑 | 带文本坐标提示与帧级二值选区的受限外观编辑，按分辨率限制单次连续帧数 | 是 | 本地二值后合成锁住选区外零渗漏，同时防范境界线与动作连续性断裂 |
| L3 局部窗口重绘 | 保留窗口外满意帧，以局部偶数窗口真实首尾帧为条件短视界重绘 | 是 | 逐帧与逐段受重试预算封顶，不静默扩大修改范围 |
| L4 整段最大窗重画 | 重绘当前段最大合法偶数可编辑区间（兼顾锁定首尾与内部锚点切分） | 是 | 改动与成本最大，作兜底策略并构成消融基线 `redraw_only` |

**修改前后解耦对比复核**：鉴于 L2 后合成仅能保证域外零渗漏而不能保证接缝连续，生成式局部修复备选需对照原版与选区叠加图，分别评判**目标是否达成（`change`）**与**非目标区域及连续性是否保持（`preservation`）**——选区零像素改动直接判失败，且局部改善不能抵消邻近区域退化。

## 6. 研究问题（RQ）

- **RQ1（漂移规律与失效谱系）**：黑盒生成器分段接续时，客观几何与色彩漂移如何随段位累积？柔性角色与刚体交互物在失效分布上有何差异？
- **RQ2（守卫检查点 vs 等调用次数基线）**：在双人独立标注的冻结语料上，相比 2 次基线与等调用次数（5 次）无守卫投票/多视角基线，程序化守卫与确定性探针能带来多大的风险–覆盖率（Risk–Coverage）收益？保留矛盾与确定性探针的 2×2 消融各自贡献多少？
- **RQ3（端到端工作流权衡）**：在统一冻结方案、种子与预算下，五种接续策略在盲评游戏可用率、技术 QA 通过率、API 费用与检查点人工升级率（Escalation Rate）上处于怎样的权衡前沿？
- **RQ4（分级修复 vs 整段重画）**：相比仅允许最大合法偶数窗整段重画（`redraw_only`），开放 L1–L4 分级修复能减少多少重绘帧数与 API 成本、提升多少局部挽救成功率？

## 7. 实验设计（三层递进验证）

实验按“零费用历史分析 → 仅 VLM 费用离线基准 → 冻结协议在线配对主实验”推进；正式付费前预注册任务清单、种子、标注手册与停止规则。

### 7.1 第一层：历史作业客观漂移分析（RQ1，零新增费用）

清点本机/Windows 存档的真实角色作业，按产生时的系统版本分层统计，避免跨版本混杂。双轨分析：① 人工标注主要失败类型（身份改变、装备缺失/增生、朝向错乱、接缝跳变、锚点漂移、动作抢演/未到位）及段位退出率；② 离线脚本逐段计算相对参考图的地面基线偏移、面积变化率、轮廓 IoU 与调色板偏离度，绘制随段位变化的客观漂移曲线。本层定位为描述性动机研究，不作因果推断。

### 7.2 第二层：冻结语料离线复核与等成本消融（RQ2，仅 VLM 费用）

- **语料与标注**：选取历史与先导角色/交互物片段构建哈希锁定的只读语料，明文定义三态标注规范（含真值 `uncertain` 判定标准），由 $\ge 2$ 名独立标注员背靠背标注并报告 Krippendorff's $\alpha$。严格划分为**开发集**（唯一允许标定探针阈值与探索工作点）与**独立保留集**（定稿后只运行一次）。
- **对比条件**（评测代码中错误拒绝记 `false_positive`，错误放行记 `false_negative`）：
  1. `baseline_2call`：先观察后审计 2 次基线；
  2. `equal_compute_vote`：等调用次数（5 次）同模型独立盲采样多数投票；
  3. `experts_no_guard`：等调用次数（最多 5 次）多视角+争议复核，关闭程序化守卫与探针；
  4. `full_guarded` 与 **2×2 离线反事实消融**（保留矛盾开/关 × 确定性探针开/关），输出 **3×3 混淆矩阵**、六项防退步计数及阈值扫描 **错误放行率–自动覆盖率（Risk–Coverage）曲线**。另抽测至少一种第二款 VLM 检验跨评审器鲁棒性。

### 7.3 第三层：冻结协议在线配对主实验与修复消融（RQ3、RQ4）

- **角色五组工作流配对比较**（全任务与 $\le 16$ 帧共同可行子集分列报告）：
  1. `single`（一次生成）：全动作单次请求（结构化简报确定性去重共享头；超 16 帧或超长受阻记入全分母）；
  2. `blind`（盲目接续）：自动取上段真实末帧接续，无复核、无修复；
  3. `keyframe_first`（论文定名 **Unverified Endpoint Proposal / 未验证端点提案**）：无外部目标图时由初态生成 4 帧终态提案锁末帧，再做首末图分段填充；
  4. `model_only`（纯模型门控）：完整 VLM 复核（禁止人工介入），通过即接续，失败至多执行一次最大合法偶数窗重画；
  5. `human_verified`（完整方法）：可编译合同 + 守卫检查点 + L1–L4 分级修复，研究者按预注册规程处理系统升级的人工裁决；自动记录检查点**升级率（Escalation Rate）**、交互次数与操作耗时。本组定位为完整人机协同工作流净效应对比，不作多被试用户研究。
- **修复分级消融**：同等 `human_verified` 协议下对比完整 L1–L4 与 `redraw_only`（仅最大合法偶数窗整段重画），统计重绘帧数、API 费用、局部挽救率与工具分布。
- **交互物刚体压力测试（小规模）**：覆盖色变/发光、平面内铰接转动、形变及带遮挡刚体平移的 2–3 状态链，分列报告**状态图、单条过渡、整条状态链**三类通过率；在出现底座偏移的失败片段上配对评估固定区回填（T1）与整数对齐（T3）的改善率及运动区副作用。
- **盲评与统计**：三重终点分别报告完整生成率、技术 QA 通过率、双人独立盲评游戏可用率（盲评页附统一格式需求与原图，非循环播完即停）；按对象/动作聚类 bootstrap 计算置信区间。

## 9. 审稿质疑与应对预案

| 潜在审稿质疑 | 应对要点 |
| --- | --- |
| **“5 次复核强于 2 次基线，只是堆调用次数吗？”** | Section 6.1 直接对比等调用次数（5 次）多数投票与无守卫多视角基线，用 Risk–Coverage 曲线分离出程序守卫与探针的净收益。 |
| **“角色主实验与确定性探针是否脱节？”** | 角色侧已将地面基线、面积、质心与调色板检查接入分段守卫，使角色与交互物共用完整 2×2 消融。 |
| **“研究者自操作人工组存在主观偏倚”** | 用客观的检查点升级率、API 费用与后端操作耗时替代主观注意力叙述，由双人独立盲评裁决成品可用性，并在 Limitations 界定工作流对比边界。 |
| **“像把整个软件产品塞进 8 页论文”** | 全文只留 1 条主线 + 3 个紧耦合方法子节，旁支模块全部剥离出正席贡献，聚焦可迁移形式化规则与 Risk–Coverage 分析。 |
| **“置信度与探针阈值是否过拟合？”** | 严格隔离开发集与独立保留集，保留集报告完整阈值扫描曲线而非单一工作点。 |
| **“单一生成器与平面内铰接假设的边界？”** | 形式化面向通用短视界黑盒接口；平面外旋转显式跳过 2D 半径探针，避免将透视缩短误报为杆长漂移。 |
