## 1. 核心痛点、洞察与唯一主线

### 1.1 为什么 2D 游戏精灵不是普通短视频

通用图生视频与开放域动画容忍轻微的像素抖动、边界漂移或道具微变；但 2D 游戏精灵是受**硬性游戏不变量（Hard Game-Readiness Invariants）**约束的状态机资产——角色动画必须守住地面基线（Ground Baseline）、锚点（Anchor）、碰撞体积与随身装备持久性，交互物多状态链（A→B→C）则必须保持非活动外壳/底座静止与刚体部件几何一致。

现成商用及闭源动画生成器普遍表现为**短视界端点条件黑盒生成器（Black-Box Short-Horizon Endpoint-Conditioned Generators）**：单次仅能生成固定短视界内的帧序列，内部权重、注意力与隐状态既不可访问也不可微调，且通常不提供原生空间蒙版或骨骼硬锁定接口。制作长角色动作或多状态交互物只能分段链式接续。

### 1.2 核心洞察（Key Insight）

聚焦黑盒短视界链式生成中的单一核心矛盾：

1. **隐性不变量漂移与 VLM 裁判的双向失灵**：分段接续时最致命的并非明显崩坏，而是**“视觉看似合理、实则破坏游戏不变量的隐性漂移（Plausible-but-Invalid Drift）”**跨段累积。若直接引入视觉语言模型（VLM）自动验收，会同时遭遇两类系统性失灵：
   - **错误拒绝（False Rejects，评测代码中记作 `false_positive`）**：将正常的身体遮挡（occlusion）、透视缩短（foreshortening）或挥砍运动残影误判为装备丢失/断裂，或将规划推理脑补出的细节当作用户硬性要求；
   - **错误放行（False Accepts，评测代码中记作 `false_negative`）**：多视角综合复核时轻率覆盖独立检查发现的局部缺陷，或对像素级地面基线偏移、前景面积跳变、固定底座位移与刚体杆长伸缩存在系统性几何盲区（例如 2026-11-11 拉杆先导观察中，VLM 虽检出固定斜撑缺失，但所有 VLM 角色一致漏判了过渡中的主杆长度伸缩）。
2. **只拦不修无法交付，全段重抽代价高昂且无原生蒙版“零渗漏 $\neq$ 接缝连续”**：纯粹拒稿只能阻止坏帧传入下一段，却无法产出可用资产；而每发现局部瑕疵就整段重画不仅成本高昂，还容易改变原本满意的动作躯干或破坏相邻接缝。在黑盒模型缺乏原生空间蒙版、只能靠本地后合成锁住区域外像素的条件下，域外 RGBA 逐像素零改动并不自动保证选区边界和动作投影连续（2026-10-27 实测证实），因此必须以**有界分级局部修复 + 前后解耦对比复核**构成闭环。

### 1.3 全文唯一故事线（痛点 → 洞察 → 方法 → 验证）

- **痛点**：黑盒短视界生成器在分段接续角色动作与交互物状态链时，隐性游戏不变量跨段漂移累积；直接依赖 VLM 自动校验同时受困于“遮挡错误拒绝”与“几何错误放行”，而全段重画既昂贵又不稳定。
- **洞察**：将分段检查点建模为**选择性预测（Selective Prediction / Risk–Coverage Control）**问题——用程序化弃权守卫与确定性像素/几何探针双向约束 VLM 的错误拒绝与错误放行，再以保不变性的有界局部修复闭环处置被拦下的缺陷，只在真正必要时通过整段重画或升级人工裁决接管。
- **方法**：提出 **Verify Before You Chain (VBYC)** 框架，由三个紧耦合环节构成：① 防目标漂移的可编译状态转移合同；② 融合程序化弃权守卫与角色/交互物统一确定性探针的**守卫检查点（Guarded Checkpoints）**；③ 带有前后解耦对比的 **L1–L4 有界分级修复（Bounded Tiered Repair）**。
- **验证**：以按系统版本分层的历史真实角色作业建立客观段级漂移曲线与失败分类学（动机研究）；在独立双人标注的冻结帧语料上对比 **2 次基线** 与 **等调用次数（5 次）无守卫 VLM 投票基线**，量化守卫与探针的**错误放行率–自动覆盖率（Risk–Coverage）**收益及 2×2 消融贡献；在受控冻结协议下评估五组接续工作流与 `redraw_only` 消融在盲评可用率、API 成本与**检查点升级率（Escalation Rate）**上的综合权衡。

## 2. 核心学术贡献（Contributions）

1. **黑盒短视界链式精灵生成形式化与跨段漂移实证分析**：将角色长动作分段与交互物多状态链（A→B→C）统一建模为通用短视界端点条件黑盒生成器 $G(I_{\text{start}}, p, I_{\text{end}}^{\text{opt}}, L, s)$ 下的带不变量状态转移问题 $(\Delta, \mathcal{I})$；基于按系统版本分层的历史真实作业，联合人工失败分类与客观段级几何漂移指标（地面基线偏移、前景面积/轮廓变化、调色板偏离），实证揭示隐性漂移的跨段累积机理以及柔性角色与刚体交互物的失效差异。
2. **融合程序化弃权守卫与统一确定性探针的选择性检查点门控（Guarded Checkpoints）**：在防偏见可编译状态转移合同与上下文隔离多视角 VLM 审计之上，构建双向可见性一致性守卫、多级矛盾不沉默覆盖（No-Silent-Override），以及覆盖**角色侧**（地面基线、面积/质心跳变、调色板偏离）与**交互物侧**（遮挡扣除固定区变化、平面内铰接半径守恒）的确定性像素/几何探针；将其形式化为风险–覆盖率控制机制，并在离线冻结语料上相对**等调用次数（Equal-Compute）无守卫 VLM 基线**验证其降低错误放行与错误拒绝的净收益。
3. **有界保不变性分级修复（Bounded Tiered Repair）与端到端工作流权衡实证**：建立从零生成费像素/固定区原语（L1）、后合成区域受限外观生成（L2，配“目标达成 vs 未改动保持”解耦复核）到局部窗口重绘（L3）与整段重画（L4）的四级修复协议，明确无原生蒙版下“域外零渗漏 $\neq$ 接缝连续”的领域边界，并在统一冻结协议下量化五种接续策略及 `redraw_only` 消融的盲评可用率、API 费用与检查点升级开销权衡。

## 3. 问题形式化与统一状态转移表示

### 3.1 黑盒短视界端点条件生成器抽象

不依赖特定商业接口细节，将底层动画生成器抽象为受限黑盒函数：
$$G(I_{\text{start}}, p, I_{\text{end}}^{\text{opt}}, L, s) \to (F_1, \dots, F_L)$$
其中 $I_{\text{start}}$ 为真实首帧图像，$p$ 为受字数上限约束的文本条件，$I_{\text{end}}^{\text{opt}}$ 为可选末端引导图，$L \le L_{\max}$ 为单次受限生成帧数，$s$ 为随机种子。生成器权重、隐状态不可访问与微调，且无原生空间蒙版或骨骼约束。给定全局目标状态变化集合 $\Delta$ 与硬性游戏不变量集合 $\mathcal{I}$，链式生成需通过 $K$ 个分段产出现实可用且满足引擎碰撞、锚点与状态机契约的序列帧。实验平台实例化参数统一置于第 5 节实验设置报告。

### 3.2 角色长动作与交互物状态链的统一表示

两类游戏精灵共用同一套“状态转移合同 $(\Delta, \mathcal{I})$ + 哈希冻结真实帧检查点 + 守卫与修复”框架，区别仅在于各自绑定的动态目标、硬不变量与确定性探针维度：

| 维度 | 角色长动作（主实验：柔性有机运动） | 交互物多状态链（刚体压力测试 + 混合修复） |
| --- | --- | --- |
| 首帧输入 | 角色标准画布原图 | 交互物标准画布原图（支持原生像素图或经确定性降采样工具输入，按来源记录但不算核心方法贡献） |
| 分段与状态语义 | 连续长动作的动作阶段（如蓄力 → 挥砍 → 收势） | 具名状态间的有向过渡（A→B→C），支持状态骨架锁定段数并在提示中约束状态顺序 |
| 检查点与接续 | 确认通过后的真实播放末帧作为下一段唯一合法起点 | 确认末帧同时登记为目标状态图；支持先单独锁状态图，但续段仍要求整段过渡通过 |
| 动态目标 $\Delta$ | 关键姿势变化、重心支撑转移、运动路径与节奏边界 | 目标终态外观、运动部件位移/旋转轨迹及末态停留语义 |
| 硬性不变量 $\mathcal{I}$ | 角色身份、随身装备持久性、地面基线、朝向与接缝连贯 | 非活动固定部件/底座位置、外轮廓、刚体几何尺度、引擎触发与碰撞对齐 |
| **确定性探针维度** | **地面基线偏移、相对参考面积变化、质心速度跳变、调色板偏离**（由现有质量检查模块接入分段守卫，见 `PAPER-11`） | **遮挡扣除后的固定区像素变动**；当合同标记为画布平面内旋转时检验**枢轴–端点铰接半径守恒**（3/4 平面外透视跳过半径探针） |
| 有界局部修复 | L1 精确像素/色表替色、L2 区域锁定外观编辑、L3 窗口重绘、L4 整段重画 | 在通用 L1–L4 之上，L1 另包含交互物固定区遮挡感知回填与不裁切边缘前景的整数对齐校正 |

**范围收口**：角色/物品生成前的静态参考图局部编辑、`PixelProp` 跨分辨率像素化算法细节以及交互物面板零生成派生工具（色表状态图、旋转草稿与反向过渡），均作为工作台系统配套保留在产品代码中，**不计入模型链式生成通过率，也不展开为本篇 8 页论文的方法或实验主线**。循环待机动画（如火焰、旗帜）属首尾闭环拓扑约束，不在本篇实验范围内。

## 4. VBYC 方法：可编译合同、守卫检查点与有界修复

方法章节沿主线收敛为三个紧密衔接的核心机制，阐述跨生成器可迁移的算法与逻辑约束，不罗列工程文件名与防御性常量。

### 4.1 防目标漂移的可编译状态转移合同（Compilable State-Transition Contracts）

针对自然语言自由规划容易引发的“装备脑补”与“提示超限截断/提前抢演”：
1. **首轮上下文隔离与原文逐字溯源降级**：外观观察与运动规划在首轮彼此隔离；针对角色任务，首次独立外观观察在不提供用户动作文本的条件下进行，仅依据参考图像记录初始外观与持械状态，防止动作语义诱导外观幻觉。后续汇总形成结构化需求合同时，程序将用户原始描述与骨架拼成真值语料库，逐条核验 LLM 标注来源为“用户要求”的引证字段是否属于原文**精确子串**——凡未命中精确子串的条款，一律自动降级为“专家推测”并把逐字用户原文注入合同；若附带已核对的视觉结构，规划器引用部件/锚点时须受限于可见部件白名单，且交互物强制将可见部件互斥完备地划分为运动部件与固定部件。
2. **确定性分段简报编译**：禁止协调模型自由撰写单段底层生成提示词。协调者仅允许填写结构化阶段目标、全局关键帧路标、运动约束以及三态段尾边界（过境连续 / 自然收势 / 有意停留，程序硬性禁止过境段将停留区间延伸至段尾），再由编译器确定性地把全局关键帧号映射为段内局部坐标、组装为标准化 12 槽绘图简报并严守生成器长度上限，超限时退回原角色精确调整而非静默截断。

### 4.2 选择性弃权守卫与确定性探针检查点（Guarded Checkpoints）

将每个分段的视觉与程序检查建模为**选择性预测决策**：高置信一致通过、明确缺陷拦截、或**显式弃权并升级人工裁决（Abstain / Escalate）**。

1. **Observe-Before-Audit 与多视角争议核实**：
   - 两步基线要求先在屏蔽质量合同的条件下严格按 `[1..N]` 逐帧记录客观姿态、装备变化与相邻帧差异，再结合任务合同进行分维度审计（角色：完整性、装备、节奏；交互物：状态帧、过渡、固定部件）。
   - 多视角审计使用**同一视觉语言模型配置**在隔离上下文中分别从“外观身份”与“运动时序”视角独立复核（明确界定为 *Context-Isolated Multi-Perspective Auditing*，非多模型集成）。**只要基线与两位独立专家的三方意见不全为高置信通过**——无论是维度分歧、低置信度或不确定、还是三方一致判为缺陷时的**缺陷核实（`verify_claimed_defect`）**——均触发至多一次争议复核；复核输入附加共享源坐标裁切（联合非透明包围盒微扩边）后的最近邻放大聚焦图板，输出“满足、实质缺陷、审美偏好、证据不足”四分类。
2. **三类程序化弃权守卫（Programmatic Epistemic Guardrails）**：
   - **最小帧证据门槛与非对称置信门限**：强制所有维度引用的帧号落在有效实际帧范围内，且完整性与时序维度必须引用足够数量的不同实际帧（不足即降级为弃权）；对通过与失败采用非对称汇总置信门限，其固定工作点与灵敏度影响在离线语料上通过阈值扫描客观评估。
   - **结构化可见性证据一致性守卫**：在装备与固定部件维度强制模型同步报告对象可见性、遮挡/透视解释与前后参考帧，并在追踪结构中明确记录 `verified_geometry=False`（表示检验模型自报语义与帧索引的内部自洽性，不声称进行了三维几何重建）。本地守卫执行双向校验：判“失败”但缺乏可见部位矛盾帧或合理遮挡排除时降级为弃权（抑制遮挡误杀）；判“通过”但存在未解释的不可见区间或拿观察帧自身充当上下文时亦降级为弃权（抑制盲目放行）。
   - **多级不沉默覆盖（No-Silent-Override）**：争议复核试图将基线非通过维度单方面翻案为通过、争议复核交出空可见性证据试图清除专家疑点、或独立专家已以高置信度给出明确可见矛盾支撑的缺陷结论被单方面翻案时，程序一律保留原始矛盾分歧并强制转为弃权升级，绝不通过多数投票静默抹平冲突。
3. **角色与交互物统一的确定性探针（Fail-Closed）**：
   - 为弥补纯 VLM 对像素位移与刚体尺度的系统性盲区，对每个分段同步运行无需付费生成的确定性测量探针：
     - **角色探针**：度量地面基线垂直偏移、相对原图的前景面积变化率、相邻帧质心速度与突变、以及色彩方案偏离度（复用质量检查器并接入分段守卫，`PAPER-11`）；
     - **交互物探针**：基于本地部件掩码追踪扣除可见运动部件的合法遮挡后，度量非活动固定区的显著像素变动；并在合同明确标注**平面内旋转（`in_plane`）**时检验参考枢轴到端点部件投影质心的半径守恒（3/4 视角等平面外旋转显式跳过半径校验，避免将合法透视缩短误报为杆长漂移）。
   - 凡 VLM 判为通过而确定性探针越界报警、或必需追踪信号不可用时，检查点一律按 **Fail-Closed 原则强制降级为弃权升级**。检查点最终确认的真实播放帧连同版本哈希永久固化，作为下一段生成的唯一合法输入；若目标姿势提前到达，支持人工显式截尾锁定较早锚点帧。

### 4.3 有界保不变性分级修复（Bounded Tiered Repair）

当检查点拦截或升级局部缺陷时，系统提供按空间修改半径与生成模型参与度递增的四级修复阶梯，避免动辄整段重抽：

| 级别 | 修复机制 | 模型绘图调用 | 作用域与不变性保障 |
| --- | --- | --- | --- |
| L1 确定性像素与固定区原语 | 选区零像素改动校验下的精准像素/色表替色、擦除补洞；交互物固定区遮挡感知回填与不裁切边缘前景的整数对齐校正 | 否（零生成费） | 0 绘图费用；跳过已锁定边界帧；提交后服务端核验授权选区外 RGBA 四通道零改动 |
| L2 区域锁定受限外观编辑 | 带文本坐标提示与帧级显式二值选区的黑盒外观编辑，按分辨率分档限制单次连续可编辑帧数 | 是 | 本地二值后合成强制锁住授权区外 RGBA 零渗漏；同步防范域外无变化下的动作与边界接缝断裂 |
| L3 段内局部窗口重绘 | 保留窗口外部已满意帧，锁定局部偶数窗口真实首尾图像作为条件执行短视界重绘 | 是 | 逐帧与逐段受重试预算封顶；严禁将局部外观请求静默改为全重绘 |
| L4 整段最大窗重画 | 覆盖当前段最大合法偶数可编辑区间重绘（兼顾锁定的首尾与内部状态锚点切分） | 是 | 成本与重构范围最大，仅作为兜底策略，同时构成修复消融中的 `redraw_only` 对照基线 |

**修改前后解耦对比复核**：鉴于 L2 在无原生蒙版条件下仅靠后合成“域外零渗漏 $\neq$ 接缝连续”，生成式局部修复备选复用现有复核框架并同时对照原版与授权区叠加图，分别给出 **目标是否达成（`change`）** 与 **非目标区域及连续性是否保持（`preservation`）** 两个独立判定——选区无任何像素变化硬判失败，且改善收益不可抵消相邻部位退化或跳变。

## 6. 研究问题（Research Questions）

- **RQ1（跨段漂移累积与失效谱系）**：黑盒短视界生成器在逐段接续 2D 游戏精灵时，客观几何/色彩漂移指标如何随段位增长而累积？柔性角色动作与刚体交互物在失效分布上有何结构差异？
- **RQ2（守卫检查点 vs 等调用次数 VLM 基线的风险–覆盖率收益）**：在独立标注的冻结帧语料上，相比 2 次基线以及**等调用次数（5 次）无守卫多数投票 / 多视角汇总基线**，程序化弃权守卫与确定性探针能在多大程度上降低错误放行率并保持可接受的自动决策覆盖率？在角色与交互物两类资产上，“矛盾保留规则”与“确定性探针”的 2×2 各自增益几何？
- **RQ3（端到端接续工作流的质量–成本–升级率权衡）**：在统一冻结方案、种子与预算上限下，五种接续策略在盲评游戏可用率、技术 QA 通过率、API 费用以及**检查点人工升级率（Escalation Rate）/ 操作耗时**上处于怎样的权衡前沿？
- **RQ4（有界分级修复相对整段重画的性价比）**：相比只允许覆盖当前段最大偶数窗口整段重画（`redraw_only`），开放 L1–L4 有界分级修复（及交互物固定区确定性原语）能减少多少冗余重绘帧数与 API 成本、提升多少局部修复成功率？

## 7. 实验设计（三层递进验证方案，具体样本量与经费待定）

为在控制成本的同时确保学术严谨性，实验分为“零费用历史研究 → 零绘图费离线复核基准 → 冻结协议在线配对主实验”三层推进，正式付费前须预注册任务清单、种子、标注手册与停止规则。

### 7.1 第一层：历史作业回顾与客观段级漂移曲线（对应 RQ1；零新增费用）

- **数据源**：清点并导出本机/Windows 存档的真实开放动作角色作业及早期历史作业（`PAPER-01`），严格按产生时的**系统/协议版本分层统计**，避免跨版本混杂。
- **双轨分析**：人工标注主要失败类型（身份改变、装备缺失/增生、朝向错乱、接缝跳变、锚点漂移、动作抢演/未到位）及段位退出率；同时在导出脚本上逐段自动计算与首帧参考的**地面基线偏移、前景面积变化率、轮廓 IoU 与调色板偏离度**（`PAPER-12`），绘制随段数变化的客观漂移曲线。声明仅作存在筛选偏差的描述性动机研究，不作因果推断。

### 7.2 第二层：冻结帧语料上的离线复核与等成本消融实验（对应 RQ2；仅 VLM 费用）

- **独立标注的冻结语料（开发集 + 保留集）**：从历史与先导序列中选取角色与交互物片段构建哈希锁定的只读评估语料，明文定义三态标注规范（包含哪些模糊情形应标为真值 `uncertain`），由 **$\ge 2$ 名独立标注员**背靠背标注并报告一致性（如 Krippendorff's $\alpha$）。划分**开发集**（唯一允许用于标定角色/交互物探针阈值及探索工作点）与**独立保留集（Held-out Set）**（仅在最终定稿后运行一次报告结果）。
- **对比条件（直接回答等调用次数质疑）**：
  1. `baseline_2call`：Observe-Before-Audit 2 次调用基线；
  2. `equal_compute_vote`：**等调用次数（5 次）**同模型独立多次采样多数投票基线（`self_consistency`）；
  3. `experts_no_guard`：**等调用次数（最多 5 次）**多视角 + 争议复核但关闭程序化弃权守卫与探针；
  4. `full_guarded` + **2×2 离线反事实拆解**：保留矛盾开/关 × 确定性探针开/关四格（通过 `counterfactual_verdicts` 逐维 `checks_by_condition` 评估），并在置信度阈值上做扫描绘制 **错误放行率（False-Accept Rate）vs 自动覆盖率（Coverage）** 曲线，同步报告 **3×3 三态混淆矩阵** 与六项防退步计数。另抽测至少一种第二款 VLM 视觉模型检验守卫规则的跨评审器鲁棒性。

### 7.3 第三层：受控冻结协议下的在线配对主实验与修复消融（对应 RQ3、RQ4；待冻结协议 `PAPER-07`–`PAPER-09` 后启动）

- **角色主实验——五组工作流配对比较**（全任务覆盖率 + $\le 16$ 帧共同可行配对子集分列报告）：
  1. **一次生成（`single`）**：全动作单次请求生成（结构化简报确定性共享头去重；超 16 帧或超 1,000 字符按本地预检受阻记入全分母）；
  2. **盲目接续（`blind`）**：逐段自动取上一段真实末帧接续，无视觉复核、无修复；
  3. **从初态生成的未验证端点提案（论文定名 *Unverified Endpoint Proposal*，代码标识 `keyframe_first`）**：每段未提供外部目标时从原始参考图生成 4 帧终态提案并锁定其末帧，再执行首末图分段填充；
  4. **纯模型门控（`model_only`）**：使用完整 VLM 复核（禁止任何人工干预），自动通过即接续，未通过至多执行一次段内合法偶数窗口重画；
  5. **完整方法（`human_verified`）**：可编译合同 + 守卫检查点与探针 + L1–L4 有界分级修复，由研究者严格按预注册操作规程响应系统升级的人工裁决；系统自动记录检查点**升级率（Escalation Rate）**、人工交互次数与后端操作耗时（补充自报时长）——明确将整套实验定位为完整人机协同工作流的净效应对比，而不冒充无偏差多被试用户研究。
- **修复分级消融**：在同等 `human_verified` 协议下对比完整 L1–L4 工具集与 `--repair-policy redraw_only`（仅允许最大合法偶数窗整段重画），统计每条序列的重绘帧数、API 费用、局部挽救成功率及工具采用分布。
- **交互物刚体压力测试（小规模）**：覆盖色变/发光、画布平面内铰接转动（`in_plane`）、形变及带遮挡刚体平移的 2–3 状态链，**严格分列报告状态图通过率、单条过渡通过率与整条状态链通过率**；并在同一批出现底座偏移的失败片段上配对评估 `T1/T3` 确定性原语的固定区改善率与运动区副作用。
- **三重终点与盲评统计**：分别报告完整候选生成率、技术 QA 通过率、双人独立盲评游戏可用率（盲评包附统一格式任务需求与原图，`PAPER-09`；非循环动作默认播完即停）；以对象/动作为聚类单位执行聚类 bootstrap 计算置信区间。

   - 阈值预注册核查：`PAPER-11` 代码接线与单元测试已闭环；真实素材到位后需先用固定开发集验证并冻结角色/交互物阈值，再在独立保留集上报告一次。
3. **第二阶段——只花 VLM 费用的离线复核基准（脚本已就绪，待素材后运行）**：
   - 完成 `PAPER-12` 冻结 `ReviewEvidence` 语料构建（$\ge 2$ 名独立标注员、计算一致性、冻结开发集阈值并在保留集单次测试），使用已就绪的 CLI 子命令运行 `baseline`（2 次）、等成本 `self-consistency`（5 次）与 `experts-no-guard`（至多 5 次）及跨模型鲁棒性测试，率先拿到 RQ2 硬数据。
4. **第三阶段——冻结在线协议并执行付费主实验**：
   - 落地 `PAPER-07`（统一 `model_only` 与 `human_verified` 运行级预算及多层完成态结局）、`PAPER-08`（回放断点恢复与 `hold_frames` 对齐）与 `PAPER-09`（盲评 `run_id` 对账与任务/原图展示），拍板 `PAPER-02` 是否加测静态关键帧对照；补充额度后按算准的样本量一次性跑完在线主实验与双人独立盲评。

## 10. 审稿攻防预案

| 审稿人核心质疑 | 应对策略 |
| --- | --- |
| **“5 次专家复核比 2 次基线强，是不是只是多花调用次数的堆算力效果？”** | Section 6.1 直接上**等调用次数（5 次）多数投票基线**与 **无守卫专家汇总基线**，配 Risk–Coverage 曲线证明收益主要来自双向可见性守卫、不沉默覆盖与确定性探针，而非调用次数本身。 |
| **“角色主实验没有确定性探针，主实验岂不是和核心机制脱节？”** | 通过 `PAPER-11` 零生成费把已有地面基线、面积、质心与调色板检查正式接入角色分段守卫，使角色主域与交互物副域共用完整的 2×2 消融（保留矛盾 × 确定性探针）。 |
| **“人工检查点 `human_verified` 由作者本人操作，存在自动化偏差与主观偏倚”** | 放弃无法证明的“人类认知选择性注意力”表述，改报客观的**检查点升级率（Escalation Rate）**、API 成本与盲评结果；由双人独立盲评裁决最终产物可用性，并在 Threats to Validity 坦诚界定为工作流净效应对比而非多被试 HCI 实验。 |
| **“核心机制太多、像把整个软件产品塞进论文（工程流水账）”** | v8 严格裁剪为 **1 条主线 + 3 个方法子节**，把静态图编辑、`PixelProp` 量化细节与 `T5/T8/T9` 派生全部移出正席贡献，所有底层常量与工程细节让位于可迁移的形式化规则与 Risk–Coverage 分析。 |
| **“置信度 0.80/0.85 或探针阈值是否拍脑袋过拟合？”** | 严格区分开发集与独立保留集，在保留集上报告完整阈值扫描下的 Risk–Coverage 曲线而非单点巧合。 |
| **“单一闭源生成器（PixelLab）与平面内铰接假设的适用边界？”** | Section 3.1 与 Discussion 明确面向 $G(I_{\text{start}}, p, I_{\text{end}}^{\text{opt}}, L, s)$ 通用抽象，并显式引入 `rotation_plane` 限制平面外透视时跳过半径探针，避免重犯透视缩短误杀。 |
