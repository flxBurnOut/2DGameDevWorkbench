## 记录

- **原请求恢复。** 交互物页面在提交前保存原载荷。工作台的稳定 `commandId` 用于准备、运行和查询。原生服务先保存绑定回执，再发布可规划的作品。恢复线程会发布已有回执的准备记录。沿用默认原生请求键的首次规划可在丢失提交响应后只读查询原作品。[原生请求回归](../../../Tools/SpritePipeline/tests/test_open_motion.py) · [工作台原生回执回归](../../../tests/workbench-adapters/native-recovery.mjs)
- **版本与存储。** 作业产物按版本和可用哈希校验后发布。任务刷新串行保存，过期后台执行可以归档。资产摘要从最新持久记录重建。共享文档重连恢复持久日志，导入和交付只发布完整内容。[跨标签页验证](../../../tests/editor-documents/request-journal.mjs) · [素材包验证](../../../tests/asset-packages/core.mjs) · [Godot 安装验证](../../../tests/game-export/install-lock.mjs) · [Python 存储与 Windows 发布验证](../../../Tools/SpritePipeline/tests/test_quota_result_safety.py)
- **前端与专家规划。** 隔离 Chrome 复验了刷新后重试、目标 PNG 保留、从冻结骨架回填、历史图片及实际初态。规划先检查已知最低预算，协调者必要时使用最后一次额度提交定稿或待确认事项。[浏览器验收](../../../tests/interactable-motion/browser.mjs) · [预算预检](../../../Tools/SpritePipeline/tests/test_prop_planning_limits.py) · [末轮定稿](../../../Tools/SpritePipeline/tests/test_planning_correction.py)

类型检查、lint、生产构建和公开文件范围检查通过。Agent 验收、MCP、HTTP、适配器、开放动作、资产库、原图、物品、交互物动画、共享文档、素材包和交付回归通过。Godot 4.7.2 在隔离工程完成播放、重启、暂停、提示和动画合并。SpritePipeline 初次全量运行有 817 项通过、2 项跳过、54 个子测试通过。两处失败分别为故障注入位置已变更和 Windows 临时占用，修正后覆盖这两处与同类帧修复的定向复验 10 项通过。测试使用隔离夹具和模拟服务。
