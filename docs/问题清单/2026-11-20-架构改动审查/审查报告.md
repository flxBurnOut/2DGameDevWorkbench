## 2. 已核对的设计点

- **付费调用不重复提交。** 核对了所有付费路径：sprite-pipeline 的 create、create-and-generate、generate-existing、plan-motion、revise-motion、generate-motion，reference-art 的 generate，以及非本地的 image-assets。它们都在发出请求前通过 `beginSubmission` 把阶段记为 `submitting`。只有停在 `preparing` 的任务会在崩溃后退回 `prepared`，此时尚未发出请求。非付费操作在调用适配器前进入 `working`，崩溃后显示待核验，不会自动退回。
- **动画授权中断不重复建 Job。** 建好 Job 而作品未回写时，重试会因 `create_job` 按 `request_key` 去重拿回同一个 Job；指纹不一致则返回冲突。
- **锁跨进程生效。** 任务锁基于 SQLite `BEGIN IMMEDIATE`；后台执行者每次写入前核对自己的令牌，令牌被替换时放弃写入。发布记录的写入与刷新补登都在同一任务锁内。
- **论文取帧规则一致。** 新的 `playback_indices` 与旧代码逐条等价：appearance 取中间帧，transition 仅去掉可确认的上下文首帧，其余帧数不符一律拒绝。
- **配对失败不外发请求。** 指纹或协议不匹配时 Web 直接返回 409 `WORKSPACE_MISMATCH`；Bridge 对带错误指纹的请求同样拒绝，覆盖了探测后监听者被替换的情况。
