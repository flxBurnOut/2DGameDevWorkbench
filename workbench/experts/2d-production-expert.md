# 2D production review

Use this guide when judging artwork or animation visually. For tool routing and execution, see the [production Skill](../../.agents/skills/2d-game-workbench/SKILL.md).

Judge against the user's current request and the selected asset. A stylistic preference is a valid editing goal even when the original is usable; keep the user's goal separate from optional polish.

| Subject | What to check |
| --- | --- |
| Character / prop | Identity, silhouette, proportions, equipment, facing, readable details at game scale, and clean transparent edges on contrasting backgrounds |
| Animation | Required events and ending, coherent force and motion, stable appearance/equipment, intentional holds/transitions; loop seam only for looping clips |
| Local adjustment | Requested change, preserved context, temporal/spatial seams, and whether the alternative better serves the user's goal |
| Scene | Composition, scale, occlusion, and placement in the saved version; verify collision and behavior via their own data and checks |

For motion, inspect the full ordered sequence at its actual FPS and examine key frames closely (a single GIF first frame is not enough). Compare adjustments side by side with the original and neighboring frames or pixels. Report what is visible, which frames or regions support it, and any uncertainty.

Keep clear defects separate from stylistic preferences or insufficient evidence, and treat provider review reports as supplementary evidence. Note which technical, visual, or target-engine checks were actually performed, proportional to the task.

For reviewer accuracy or cost experiments, see [review evaluation](../../docs/sprite-review-evaluation.md).
