# 部件属性计划、简单换色与独立复核

本指南介绍图片局部调整工作区中的试验功能：用视觉模型辅助定位部件、按属性计划生成或本地换色、修正 AI 合成区，以及独立复核成品。

## 前置配置

- 部件定位读取序列帧模型设置中的 `appearance` 角色，成品复核读取 `reviewer` 角色；复用本机受保护凭据（兼容旧图片凭据回退）。
- 连接外部 SpritePipeline 时读取其公开模型角色，发送请求仍需本机凭据可用。
- 视觉规划、图片生成和成品复核都是各自独立的显式调用；每份定位记录最多规划一次，每份计划最多提交一个候选，断线后查询原记录恢复。

## 1. 粗框定位与部件建议

1. 在画布框出允许修改的最大范围，填写目标部件与要求（例如“石座下方正面的圆形徽章”），点击 **准备部件定位视图（本地）**。
2. 界面展示待发送的三张视图（全图缩略图、干净局部图、带授权标色的局部图），核对后点击 **发送这三张视图并定位** 发起一次视觉请求。
3. 模型返回部件描述、目标框（黄框）、建议保护区（红框）、五项属性策略（轮廓/位置、纹理、底色、明暗、反光）与成功条件；若越界或与透明度锁冲突，界面会标出待修正项。
4. 核对并采用建议：
   - 保留现有手选区：点 **只载入属性，保留手选范围**。
   - 调整模型框：在干净局部图上拖动重画或微调像素坐标，逐项勾选保护区后点 **使用核对后的框和属性**（已有手动保护区会保留）；不规则轮廓可在主画布涂选后点 **将当前选区设为目标**。

## 2. 制定属性计划与参考图

1. 从保形换色、替换材质或替换部件策略出发，逐项确认五项属性的保持/修改/重算要求。
2. 细化最大范围 `U`、目标区 `T`、允许影响区 `F` 和保护区 `P`，实际可写区为 `W = U ∩ (T ∪ F) − P`（原图整数像素坐标，未单设目标时 `T = U`）。保护区逐像素恢复；需要改变透明轮廓时关闭 **保持透明度**。
3. 可选参考图：
   - `image-plan-prepare` 传 `localContext: true` 可附上同一基准的干净局部裁切图用于定位（仍要求输出完整原图）；
   - 可额外提供 `softReference: {kind: "rgb"}` 作为同尺寸同坐标 RGB 对照；
   - 参考图总数上限 8 张（用户参考在前），满 8 张时不会静默替换，会提示未加入局部参考。参考图不扩大已确认的蒙版授权范围。
4. 点击 **准备计划并预览范围** 冻结输入并预览绿色实际可写区与局部参考（此步不生成）；修改基准、范围、描述或策略后须重新准备。

## 3. 执行：简单本地换色或 AI 生成

- **简单本地换色（`color-map`）**：无需 Python、模型 Key 或外部调用。先在画布划掉需保留原色的细节（如藤叶、金属边饰），再按需选算法：
  - `luminance`（保留相对明暗，统一色相）：在线性 RGB 中按原亮度与原底色亮度比缩放目标色（原底色样本需亮于纯黑）；
  - `rgb`（默认，RGB 通道比例）：保留各通道原有差异。
- **AI 外观生成**：使用当前修改描述、参考图与冻结计划提交候选；换色类建议优先用本地换色并核对原底色与目标色。
- **修正合成区（`recompose-ai`）**：在锁定透明度的已完成 AI 候选中，若原始返回已画对但最终图漏留旧色，可展开 **检查原始返回并修正合成区**，在最大授权区内重新圈选并减去保护像素，点击 **用当前选区重新合成（本地）**。新候选从原基准派生，选区内取原始返回 RGB，全图 Alpha 与选区外取自基准。

## 4. 独立复核成品与缺陷诊断

1. 在已完成候选上展开 **独立复核成品**（生成候选沿用原指令，本地候选需填写目标），点 **准备成品复核（本地）** 预览原图与成品的摆放尺寸、全貌、局部共 6 张图。
2. 核对服务与视图后点击 **发送并复核成品**。首轮复核在独立模型上下文中进行，按目标、保持内容、边界与摆放效果记录原图坐标缺陷。
3. 若复核失败或证据不足，且候选留有完整原始返回，可继续准备并发送 **缺陷诊断**（追加原始返回、最大授权区与实际合成区），以决定走本地重合成、改计划还是人工处理。
4. 刷新、断线或补配 Key 后，点击 **查询原复核记录** 找回回执；只读入口、历史来源和锁定目标支持查询已有回执，发起新复核要求当前目标可编辑且版本未变。

## 5. 接口与恢复

完整参数见[图片编辑契约](../../lib/workbench/image-edit-contract.mjs)，网页经 Bridge 与 MCP 共用同一接口：

| CLI / Bridge 操作 | MCP 工具 | 用途 |
| --- | --- | --- |
| `image-part-context` | `workbench_prepare_part_context` | 本地冻结三张定位视图、粗框、基准与指令，返回 `partRef` |
| `image-part-suggest` | `workbench_request_part_suggestion` | 对 `partRef` 发起一次视觉定位规划 |
| `image-part-get` | `workbench_get_part_suggestion` | 查询定位记录与回执（MCP 原生返回图片） |
| `image-plan-prepare` | `workbench_prepare_image_plan` | 绑定目标/版本/选区，冻结属性策略与参考，不生成 |
| `image-plan-get` | `workbench_get_image_plan` | 读取已有计划 |
| `image-edit` | `workbench_edit_image_region` | 携带 `regionRef` 与 `planRef` 提交编辑；`recompose-ai` 仅本地重合成 |
| `image-review-record` | `workbench_record_image_review` | 记录当前查看者的判断与缺陷坐标（不自动采用） |
| `image-critic-prepare` | `workbench_prepare_candidate_check` | 本地冻结 6 张复核视图；传 `parentReviewRef` 准备缺陷诊断 |
| `image-critic-run` | `workbench_request_candidate_check` | 发起一次独立模型复核或诊断 |
| `image-critic-get` | `workbench_get_candidate_check` | 按 `reviewRef` 找回复核记录与视图 |

- 重复提交相同 `commandId` 返回原候选；过期计划或错误哈希会被拒绝。状态不明时凭原 `commandId`、`editId` 或 `reviewRef` 查询恢复，不要换 ID 重发。
- 回归验证：`npm run test:image-attribute-plan`（其余图片编辑回归见[开发导航](development.md)）。
